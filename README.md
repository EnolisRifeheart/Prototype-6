# Prototype 6
by Geuddy Perez


Salutations. This is a prototype a 10-second Memory Match Game.

Controls

Click to interact and match image pairs.


What went well?

Setting up everything in the inspector, learning how to use Tween and making sure it animates the card flipping accurately.

What didn’t go well?

I feel like I could've added more features, or a gradual level difficulty increases.

What challenges did you face?

A matter of figuring out what else I can add into a simple game like this.

What would I aim to do differently?

Set aside more time to add like a levels where the cards increase per level, and maybe if the player finishes a level quickly enough, they can store the time from the finished level and carry it over to the next.
